# Правка PDF

Веб-приложение для правки текста внутри готового PDF. Работает целиком в браузере:
файл никуда не загружается, сервер не нужен.

Открывается по адресу `/play/pdf-editor/` (в разработке — `npm run dev`, затем
http://localhost:4321/play/pdf-editor/).

## Что умеет

- **Открыть PDF** — кнопкой или перетаскиванием файла в окно.
- **Разбор текста на абзацы.** Кусочки текстового слоя склеиваются в строки по базовой
  линии, строки — в абзацы по межстрочному расстоянию, кеглю и общей колонке.
- **Правка на месте.** Клик по абзацу — и текст правится как в обычном редакторе.
- **Перенос строк.** Длинный текст переносится по ширине блока; ширина меняется
  перетаскиванием правого края.
- **Сдвиг соседей.** Абзац вырос — блоки ниже уезжают на столько же, чтобы текст не
  наползал. Отключается галочкой слева.
- **Вписать в исходную высоту.** Кегль сам уменьшается, пока текст не влезет в прежние
  габариты, — нужно там, где раздвигать вёрстку нельзя.
- **Оформление блока:** гарнитура (без засечек / с засечками / моноширинная), кегль,
  жирность, курсив, цвет, выключка.
- **Новые надписи** в любом месте страницы, в том числе поверх сканов.
- **Удаление блока** — текст закрывается плашкой цвета подложки.
- **Перетаскивание** блока за уголок.
- **Отмена и возврат** (Ctrl+Z / Ctrl+Shift+Z), до 80 шагов.
- **Поиск по всему документу** с переходом к найденному абзацу.
- **Автосохранение черновика** в IndexedDB: правки переживают перезагрузку страницы.
- **Сохранение PDF** — скачивается новый файл, исходный не меняется.

Горячие клавиши: `Ctrl+Z` отменить, `Ctrl+Shift+Z` вернуть, `Ctrl+S` сохранить,
`Ctrl+F` поиск, `Esc` выйти из блока, стрелки — листать страницы.

## Как это устроено

| Файл | Отвечает за |
| --- | --- |
| `js/doc.js` | открытие через pdf.js, отрисовка страниц, определение шрифтов |
| `js/blocks.js` | сборка абзацев из текстового слоя, снятие цвета текста и подложки |
| `js/layout.js` | перенос строк и подбор кегля |
| `js/fonts.js` | загрузка гарнитур, метрики, регистрация в браузере |
| `js/editor.js` | слой правки над страницей, перевёрстка, перетаскивание |
| `js/store.js` | состояние, история, автосохранение |
| `js/exporter.js` | сборка нового PDF |
| `js/app.js` | панели, горячие клавиши, поиск |

Ключевая деталь: перенос строк и на экране, и в файле считается одними и теми же
метриками (fontkit), поэтому предпросмотр совпадает с результатом построчно.

Нетронутые абзацы попадают в готовый файл как есть — без перерисовки и потери качества.
Изменённые сначала закрываются прямоугольником цвета подложки, а затем печатаются
заново вшитым шрифтом.

## Ограничения

- **Шрифт при правке заменяется.** Гарнитуру из исходного PDF переиспользовать нельзя:
  туда обычно вшит только тот набор символов, что уже стоит на странице. Изменённые
  блоки перерисовываются PT Sans, PT Serif или PT Mono — программа сама выбирает
  ближайшую по имени исходного шрифта и сохраняет жирность и курсив.
- **Старый текст остаётся внутри файла**, просто закрыт плашкой. Для скрытия
  персональных данных приложение не годится — нужна настоящая редактура.
- **Повёрнутые страницы** (`/Rotate 90` и подобные) открываются только для просмотра.
- **Сканы** без текстового слоя править нечего — но поверх них можно класть надписи.
- Таблицы и многоколоночная вёрстка разбираются как обычные абзацы: сдвиг соседей там
  лучше отключать.

## Сторонний код

Всё лежит рядом с приложением: политика безопасности сайта (`public/_headers`,
блок `/play/*`) разрешает скрипты только со своего домена, внешние CDN не подходят.

| Библиотека | Версия | Лицензия |
| --- | --- | --- |
| [pdf.js](https://mozilla.github.io/pdf.js/) | 6.3.289 | Apache-2.0 |
| [pdf-lib](https://pdf-lib.js.org/) | 1.17.1 | MIT |
| [@pdf-lib/fontkit](https://github.com/Hopding/fontkit) | 1.1.1 | MIT |

Шрифты PT Sans, PT Serif и PT Mono (ParaType) — лицензия SIL Open Font License 1.1,
текст в `fonts/OFL.txt`. Файлы урезаны до латиницы, кириллицы и типографских знаков,
поэтому весят по 30–40 КБ вместо 350–470 КБ.
